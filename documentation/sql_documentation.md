# SQL Documentation

## Beginner Queries

- Total bookings and revenue.
- Booking status distribution.
- Revenue by vehicle type.
- Payment method distribution.

## Intermediate Queries

- Cancellation reasons by customer and driver.
- Pickup hotspot analysis.
- Vehicle type failure rate using `HAVING`.
- Rating summary by vehicle type.

## Advanced Queries

- Daily trend analysis using CTE and `LAG`.
- Pickup location ranking using `RANK` and `DENSE_RANK`.
- Top longest rides per vehicle type using `ROW_NUMBER`.

## SQL Concepts Demonstrated

- `GROUP BY`
- `HAVING`
- `CASE`
- CTEs
- Window functions
- `ROW_NUMBER`
- `RANK`
- `DENSE_RANK`
- `LAG`
